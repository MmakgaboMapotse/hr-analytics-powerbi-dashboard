# HR Analytics Dashboard — Power BI

## Project Overview
This project uses Microsoft Power BI to explore employee attrition and workforce patterns across departments, age groups, genders, job roles, job satisfaction levels, and monthly income groups.

## Dashboard Objectives
- Monitor total employees, employees who left, and attrition rate.
- Compare attrition across demographic and job-related categories.
- Explore how job satisfaction and monthly income groups relate to employee attrition.
- Use a department slicer to interactively filter the dashboard.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)

## Dataset
The project uses the IBM HR Analytics Employee Attrition dataset, a fictional dataset available through Kaggle.

Dataset source: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

## Skills Demonstrated
- Data preparation and transformation
- KPI cards and interactive visualisations
- DAX measures
- Slicers and report filtering
- Exploratory data analysis and dashboard design

## Project Status
The two-page dashboard has been created. Final formatting, interpretation of findings, and project documentation are being completed.

## Limitations
The dataset is fictional. Findings describe patterns in this dataset and should not be treated as evidence about a real organisation or used alone to make employee decisions.
